## 핵심 개념
`.`은 "이 객체가 가지고 있는 것을 꺼내 쓴다"는 뜻 (소속 관계). `df.info()`, `df.columns`처럼 df가 가진 메서드/속성에 접근할 때 씀. `_`는 그냥 이름(변수명, 함수명) 안에서 띄어쓰기 대신 쓰는 문자일 뿐, 소속 의미는 없음.

## 예시 코드
```python
df.info()       # df가 가진 info 기능 실행
df.columns      # df가 가진 columns 정보 꺼내기
sample_question_papers  # 그냥 변수 이름 (띄어쓰기 대신 _)
```

## 헷갈렸던 부분
`.`과 `_`의 역할을 헷갈려함 → `.`=소속(뭔가에 딸린 걸 꺼냄), `_`=이름 표기 문자로 정리.
