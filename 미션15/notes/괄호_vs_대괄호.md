# 괄호_vs_대괄호

## 질문 이력
- 2026-08-11

## 핵심 개념
`[]`는 이미 있는 것 중 하나를 이름/위치로 **꺼내는** 것(인덱싱) — 리스트의 `mylist[0]`, DataFrame의 `df['컬럼명']`이 같은 원리.
`()`는 함수나 메서드를 **실행하는** 것 — `df.info()`처럼 어떤 동작을 수행하라는 뜻.

## 예시 코드
```python
mylist = [10, 20, 30]
mylist[0]           # 10 (꺼내기)

df['Extracurricular Activities']   # 컬럼 꺼내기
df.info()            # 요약 정보 실행/출력
```

## 헷갈렸던 부분
`df[10]`처럼 인덱스와 값을 헷갈려함 → "몇 번째 자리인지"가 인덱스라는 걸로 정리.
