# 딕셔너리_기초

## 질문 이력
- 2026-08-11

## 핵심 개념
`{}`는 `키: 값` 쌍을 모아놓은 딕셔너리(dict)를 만들 때 쓴다. `df['컬럼'].replace({'Yes': 1, 'No': 0})`처럼 "이 값을 보면 저 값으로 바꿔라"는 대응표를 넘길 때 자주 쓰인다.

## 예시 코드
```python
df['Extracurricular Activities'].replace({'Yes': 1, 'No': 0})
```

## 헷갈렸던 부분
`()`, `[]`와 `{}`를 구분하는 데 헷갈려함 → `[]`=꺼내기, `()`=실행, `{}`=키-값 대응표(딕셔너리)로 정리.
