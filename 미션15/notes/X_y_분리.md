# X_y_분리

## 질문 이력
- 2026-08-11

## 핵심 개념
지도학습에서 X(feature)와 y(target)는 반드시 분리해서 모델에 넘긴다. `model.fit(X, y)`는 X와 y를 둘 다 받기 때문에 모델이 정답을 몰라서 학습을 못 하는 게 아니다. 만약 target을 X 안에도 넣어두면, 모델이 실제 관계를 배우지 않고 그 컬럼을 그대로 베껴서 "컨닝"하게 된다 (데이터 누수). 게다가 실전 test.csv에는 애초에 target 컬럼이 없어서, X에 넣어두면 실전에서 아예 쓸 수 없는 모델이 된다.

## 예시 코드
```python
y = df['Performance Index']
X = df.drop('Performance Index', axis=1)
```

## 헷갈렸던 부분
"학습 시 모델이 정답을 알아야 예측법을 배울 수 있는 거 아니냐"고 헷갈려함 → fit(X, y)에서 y가 별도 인자로 이미 전달된다는 것, X 안에 넣으면 컨닝이 된다는 걸로 정리.
